# Feedback History

## Test Case Documentation
- **Human-Centric Navigation over URLs**: When writing test cases for human users (e.g. UAT, manual testing, QA instructions), never use raw technical URLs like `/admin/financial-years` or `/login`. Always use human-readable navigation paths, menu names, button labels, tab titles, and dialog actions (e.g., "Left Sidebar > System administration > Financial years & quarters", "Click 'Add Financial Year' button", "Select 'Computed Month & Day Breakdown' tab").
